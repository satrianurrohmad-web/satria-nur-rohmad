WEBSITE PRIBADI SATRIA NUR ROHMAD
================================

Isi folder ini sudah dilengkapi dengan:
- index.html: seluruh halaman dan cerita website
- style.css: desain Glassmorphism responsif
- script.js: menu HP, penggantian tema, galeri foto yang bisa diperbesar, dan animasi ringan
- images/: 8 foto asli yang sebelumnya Satria kirimkan

CARA MEMBUKA DI CHROMEBOOK
1. Ekstrak ZIP ini terlebih dahulu.
2. Buka folder satria_portfolio_website.
3. Klik dua kali index.html. Jika diminta, pilih Chrome.
4. Pastikan folder images tetap berada di samping index.html; jangan memindahkan file HTML sendirian.

CATATAN
- Website dapat dibuka secara lokal tanpa memasang aplikasi tambahan.
- Google Fonts memerlukan internet; bila offline, website tetap terbuka dengan font pengganti.
- Website ini belum otomatis online atau terindeks Google. Agar bisa diakses semua orang, website perlu dipublikasikan melalui layanan hosting dan kemudian didaftarkan ke Google Search Console.
- Sebelum dipublikasikan, pastikan kamu nyaman membagikan semua foto dan informasi di dalamnya. Jangan menambahkan alamat rumah, nomor pribadi, atau jadwal rinci.
