WEBSITE BERANDA DEWAN PRAMUKA SMPN 1 MALO

Isi folder:
- index.html : halaman beranda
- style.css  : desain dan background
- script.js  : menu ponsel dan kuis interaktif
- assets/    : foto-foto yang kamu kirim

CARA MEMAKAI:
1. Ekstrak ZIP ini.
2. Buka folder dewan_pramuka_website.
3. Klik index.html untuk melihat beranda di browser.
4. Untuk menggabungkan ke website lama, salin bagian halaman yang diperlukan ke proyekmu dan sesuaikan link navigasi.
   File ini adalah beranda mandiri dan tidak menimpa website lamamu.

Catatan: Google Fonts membutuhkan koneksi internet; website dan foto tetap tampil tanpa font tersebut.
